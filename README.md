# fileUp

> **⚠️ Development Status**: This project is currently under development. New features and improvements are being actively developed. Please check the issues and projects sections to see what's being worked on.

Full-stack file management and processing platform developed with Java, Spring Boot, React, and
TypeScript, applying security best practices, layered architecture, and REST API development
principles. The system implements a file treatment process, secure authentication, and user
management.

> Tech: Java, Spring Boot, Spring Security, JWT, Refresh Token, Spring Data JPA, Hibernate,
PostgreSQL, Maven, React, TypeScript, React Query, Tailwind CSS, i18n, Vite, REST APIs, Git.
